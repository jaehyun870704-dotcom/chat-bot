## 2. 소요 시간 (노무 질문 10개)

| 구분 | 값 | PRD 목표 | 판정 |
|---|---|---|---|
| 임베딩 평균 | 168ms (최초 호출 1,599ms 포함 / 이후 8~10ms) | — | 양호 |
| **검색 평균** | **17,691ms** | 300ms | **미달 (약 59배)** |
| 검색 최소/최대 | 14,133ms / 21,060ms | — | — |

원인은 벡터 인덱스 부재다. `EXPLAIN ANALYZE` 결과 매 질의가 298,950행 **Parallel Seq Scan** 전수 스캔이다.
D-02(Supabase Pro) 미결로 HNSW 인덱스를 만들 수 없어 **미해결 상태로 남긴다**.

임시 조치로 RPC `match_labor_chunks` 에 함수 단위 `statement_timeout = 120s` 를 설정했다.
기본값(8초)으로는 모든 검색이 타임아웃된다. **인덱스 도입 시 이 설정을 반드시 제거한다.**

## 4. 유사도 컷오프 보정

e5 정규화 코사인은 값이 좁은 구간에 몰려 초기 컷오프 0.80은 아무것도 걸러내지 못했다.
오프토픽 질의를 넣어 분리도를 실측했다.

| 질의 성격 | 예시 | top 유사도 |
|---|---|---|
| 온토픽 (일반) | 부당해고 구제신청 기간 | 0.9277 |
| 온토픽 (벤치마크 최저) | 산재 신청 절차 | 0.8966 |
| 온토픽 (희귀 주제) | 가사근로자 최소근로시간 | 0.8868 |
| 오프토픽 | 제주도 여행 코스 | 0.8562 |
| 오프토픽 | React useEffect | 0.8484 |

온토픽 최저 0.8868과 오프토픽 최고 0.8562 사이 여유가 **0.03에 불과하다.**
따라서 컷오프는 `0.87` 로 두되, **주제 범위 가드로 쓰지 않는다.**
범위 판정은 PRD F-04 의 LLM(Haiku) 단계가 담당하고, 컷오프는 "근거 없음" 판정용 안전망으로만 쓴다.

## 5. PRD에 없던 실측 리스크

### 5.1 코퍼스 인코딩 손상 (조치 완료)

판례1~4 소스에서 CP949→UTF-8 변환이 깨져 일부 기호가 `?` 로 치환돼 있다.

| 소스 | 청크 | `???` 포함 | 비율 |
|---|---|---|---|
| 판례2 | 54,839 | 43,738 | 79.8% |
| 판례1 | 46,332 | 35,450 | 76.5% |
| 판례3 | 55,523 | 36,450 | 65.6% |
| 판례4(원본) | 23,149 | 13,428 | 58.0% |
| 그 외 전부 | 116,507 | 1 | 0.0% |
| **합계** | **298,950** | **129,067** | **43.2%** |

청크당 평균 608자 중 20.7자(5.4%)로 **한글 본문은 보존**된다. 검색 품질 영향은 관찰되지 않았다.
`search-lab/src/sanitize.js` 가 검색 직후 제거해 프롬프트·인용에 들어가지 않게 한다(원문은 `rawContent` 보존).
**임베딩 자체는 잡음을 포함한 채 생성돼 있어 재적재 없이는 보정 불가하다.**

### 5.2 랜드마크 판례가 채택 컷(8건) 바로 밖에 떨어진다

Q03(통상임금)에서 상위 8건에 **2013년 전원합의체 판결(2012다89399)이 들어오지 않았다.**
top-100까지 확대해 확인한 결과 **9위(유사도 0.9012)** 에 있었다 — top-8 바로 바깥이다.

| 측정 | 값 |
|---|---|
| 2012다89399 언급 청크 최초 등장 순위 | 9위 |
| 해당 청크 유사도 | 0.9012 |
| top-1 / top-100 유사도 | 0.9204 / 0.8852 |

즉 dense 검색이 해당 판례를 못 찾는 게 아니라, **8건 컷에서 밀린다.** 선택지는 세 가지다:
채택 수를 8→10~12로 늘리거나, 유사도 순 대신 리랭킹을 도입하거나, 키워드(BM25) 하이브리드를 얹는 것이다.
PRD §7.1 템플릿이 top-8을 전제하므로 Phase 3 답변 품질을 보고 판단한다. PRD §3.3 [5] "필요 시 개선" 범위.
