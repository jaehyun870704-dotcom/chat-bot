# PRD: 노동법 HR 실무자 챗봇 (프로젝트명 TBD)

- 작성일: 2026-09-07
- 작성: 강재현 (좋은인재연구소 GTI) × Claude
- 개발 환경: Claude Code
- 상태: v1 초안 (소크라테스식 인터뷰 기반)

---

## 1. 배경 및 문제 정의

좋은인재연구소(GTI)는 노동법 판례·지침·산재심사재결례·행정심판·행정해석·상담사례집 등
약 29.8만 개 청크 규모의 노동법 데이터를 이미 벡터화(Xenova/multilingual-e5-small, 384차원)해
Supabase(pgvector)에 적재해 둔 상태다.

외부 기업의 인사담당자·HR 실무자는 현업에서 발생하는 노동법 이슈(해고, 영업양도, 근로조건
변경, 퇴직금 등)에 대해 즉시 참고할 수 있는 판례 기반 답변이 필요하지만, 매번 변호사·노무사에게
문의하기엔 비용·시간 부담이 크다. 이 문제를 판례 기반 RAG 챗봇으로 해결하고, 유료 구독 상품으로
수익화한다.

## 2. 타겟 사용자

- **1차 타겟**: 고객사(외부 기업)의 인사담당자·HR 실무자 — 개인 자격으로 직접 가입/결제/이용
- GTI 내부 컨설턴트용 도구가 아님 — 외부에 판매하는 **B2C 유료 제품**
- (확장 예정, MVP 범위 아님) 기업/팀 단위 구독 — 한 회사가 구독하면 여러 인사담당자가 함께 사용

## 3. 목표 (MVP 범위)

- 개인 구독 모델 우선 출시. 회사/팀 구독은 이후 단계에서 확장.
- 노동법 판례·지침 기반의 신뢰할 수 있는(출처 명시) 답변 제공
- 무료 체험으로 제품 가치를 경험시키고 유료 전환 유도
- 사용량(토큰) 기반 과금으로 서버 비용을 통제하면서, 추가 결제로 확장 가능하게 함

### 범위 밖 (Out of scope, v1)

- 회사/팀 단위 구독, 팀원 초대·권한 관리
- 정식 출시 일정, 구체적 KPI/성공지표 (본 PRD 단계에서는 우선순위 낮음으로 확인됨)
- 노동법 외 법률 분야(세무, 지식재산 등) 전문 대응

## 4. 핵심 기능

### 4.1 회원가입 / 로그인
- 이메일 기반 회원가입·로그인 (소셜로그인 등은 v1 범위 아님)

### 4.2 무료 체험 & 구독
- 가입 후 **무료 질문 3회**까지 제공
- 이후 질문하려면 **개인 유료 구독** 필요
- 예상 가격대: 월 9,900원 ~ 19,900원 (미확정 — 프로모션가/A-B 테스트로 최종 결정 예정)
- 결제 수단: **국내 PG사 연동** (예: 토스페이먼츠/이니시스 등 — 구체 PG사는 개발 단계에서 결정)

### 4.3 사용량(토큰) 제한 & 추가 결제
- 구독자도 월 사용량(질문 처리에 소요되는 토큰 기준) 한도를 둠 — AI 토큰 소진 방식과 유사
- 한도 초과 시 서비스 완전 차단이 아니라 **추가 결제(토큰 충전)** 로 계속 이용 가능
- 사용량 한도 및 충전 단가는 Claude API 실제 원가를 기준으로 별도 산정 필요 (Open Item)

### 4.4 질문/답변 (핵심 기능)
- **검색**: 사용자 질문 → e5-small로 쿼리 임베딩 → Supabase `match_labor_chunks()`로 노동법
  판례/지침/자료 벡터 검색 (카테고리 필터링 가능)
- **생성**: Claude API가 검색된 근거를 바탕으로 아래 **고정 템플릿의 슬롯만** 채워 답변 생성
- **템플릿 강제 규칙 (중요)**: AI는 프롬프트로 형식을 "지키도록 유도"되는 게 아니라, 코드가
  아래 구조를 강제로 조립한다. AI는 지정된 슬롯의 본문 내용만 생성하고, 아래 고정 문구는
  절대 수정·삭제할 수 없다.

  ```
  [핵심 답변]      ← AI 생성
  [근거 자료 상세]  ← AI 생성 (검색된 판례 인용 포함)
  [실무적 적용]    ← AI 생성
  [연관내용]       ← AI 생성 (용어 설명)
  [관련판례]       ← AI 생성 (검색된 판례 목록)

  ------------------------------------------------------------
  본 답변은 업로드된 자료를 바탕으로 작성되었으며, 실제 사건 적용 시에는
  반드시 전문가의 검토가 필요합니다. 구체적인 도움이 필요하시면
  좋은인재연구소(goodhr.kr)로 문의주세요.
  ------------------------------------------------------------
  ```
  ※ 위 면책조항은 답변 상단·하단에 코드 레벨에서 항상 고정 삽입 (AI 출력에 포함되지 않음)

- **답변 범위**: 노동법/인사 관련 질문은 유연하게 답변. 명백히 무관한 주제(일반 잡담, 타 법률
  분야 등)는 "이 서비스는 범용 AI가 아니라 노동법 판례 중심 서비스임"을 안내하고, 특화된
  주제로 다시 질문하도록 유도. 무리하게 답변을 시도하지 않음.

### 4.5 대화 방식
- **멀티턴 대화** 지원 — 후속 질문("그럼 이 경우는?")에 이전 맥락을 유지하며 답변
- **채팅방(스레드) 다중 관리** — ChatGPT처럼 사용자가 주제별로 새 채팅방을 여러 개 만들고
  좌측 목록에서 전환 가능
- **대화 기록 저장** — 모든 대화는 저장되어 나중에 다시 열람 가능
- **삭제 기능 (필수 요건)** — 인사 관련 민감 정보가 오갈 수 있으므로, 사용자가 채팅방/대화를
  직접 삭제할 수 있어야 함

## 5. 데이터 & 인프라 현황 (이미 구축 완료)

| 항목 | 내용 |
|---|---|
| 임베딩 모델 | Xenova/multilingual-e5-small (384차원) |
| 데이터 규모 | 298,950 청크 (판례 236,454 / 행정해석 40,946 / 행정심판 10,558 / 산재심사재결례 7,116 / 상담사례 등 reference 2,455 / 지침 1,421) |
| 저장소 | Supabase 프로젝트 `gti-labor-rag` (ap-northeast-2, 무료 티어) |
| 테이블 | `public.labor_chunks` (pgvector, uri/category/source/title/case_link/content/embedding) |
| 검색 함수 | `public.match_labor_chunks(query_embedding, match_count, filter_category)` — 코사인 유사도 검색 |
| 알려진 이슈 | ① 무료 티어 스토리지 한도(500MB) 초과로 DB가 read-only 상태 — 벡터 인덱스(HNSW/IVFFlat) 미생성, 현재 브루트포스 검색만 가능. Pro 업그레이드 또는 중복 원본 데이터 삭제로 해소 예정. ② "판례4(원본)" 등 일부 원본 소스에 인코딩 깨짐 존재 (curated 소스로 커버되어 영향 적음) |

## 6. 답변 생성 LLM

- **Claude API** 사용 확정
- 구체 모델(Haiku/Sonnet 등)은 답변 품질과 토큰 비용(=사용량 과금 원가) 사이의 트레이드오프를
  고려해 개발 단계에서 결정 (Open Item)

## 7. 기술 아키텍처 (개략)

```
사용자(웹) → 이메일 로그인 → 채팅 UI
   ↓ 질문
Edge Function / API 서버
   ├─ 사용량(토큰) 한도 확인 (부족 시 결제 유도)
   ├─ e5-small로 쿼리 임베딩
   ├─ Supabase match_labor_chunks() 벡터 검색
   ├─ Claude API 호출 (검색 결과 + 대화맥락 → 슬롯별 콘텐츠 생성)
   ├─ 코드가 고정 템플릿(면책조항 포함)에 조립
   └─ 사용량 차감 + 대화 기록 저장
   ↓ 응답
채팅 UI (해당 채팅방에 표시, 대화 목록에 저장)

결제: 국내 PG사 연동 (구독 결제 + 토큰 추가 결제/충전)
```

## 8. Open Items (추가 논의 필요)

1. Supabase 스토리지 한도 초과 해결 방법 (Pro 업그레이드 vs 원본 중복 데이터 정리)
2. 정확한 구독 가격 (9,900원 vs 19,900원 vs 그 외) 및 프로모션 전략
3. 월 사용량(토큰) 한도 수치 및 추가 결제(토큰 충전) 단가 — Claude API 실제 원가 기반 산정 필요
4. 사용할 Claude 모델 선택 (비용 대비 답변 품질)
5. 국내 PG사 선정 (토스페이먼츠 / 이니시스 등)
6. 회사/팀 구독 모델 설계 (v1 이후)

## 9. 향후 확장 (v2+, 참고용)

- 회사/팀 단위 구독 (팀원 초대, 관리자 권한, 좌석 관리)
- GTI 1:1 스팟 컨설팅 서비스로의 업셀 연동 (챗봇 답변만으로 부족할 때 전문가 상담 유도)
